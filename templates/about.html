About This System

Multimodal Deep Learning for Phishing Detection

The live application now implements a trained DistilBERT text branch, neural metadata branch, late fusion, attention diagnostics, and metadata SHAP. Reported dissertation values below remain labelled separately from the reproducible live evaluation.

Aim

To develop an AI-based phishing email detection system using multimodal deep learning with explainable and lightweight architectures, capable of accurately distinguishing between phishing and legitimate emails while providing transparent reasoning for its predictions.

Objectives

  • Collect and preprocess phishing and legitimate email data
  • Develop a multimodal deep learning model integrating text and metadata
  • Evaluate model performance using standard metrics
  • Incorporate explainable AI techniques (SHAP, Attention Visualization)
  • Implement a lightweight, deployable system

Dataset Information

The downloaded cited archive contains 56,733 rows. The live multimodal model uses all 3,065 metadata-complete Nazario_5 rows (1,565 phishing and 1,500 legitimate); 53,668 text-only rows were excluded from multimodal evaluation because they lack sender and URL metadata.
